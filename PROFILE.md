# CoinNudge Research Data API

Crypto market research data API from CoinNudge (operated by LUMOS AI TECHNOLOGY CO LTD). Offers ~55 Research datasets and versioned Market Events releases via JSON/CSV/Parquet, covering market breadth, funding rates, open interest, liquidations, listings, options, volatility, and on-chain indicators. Bearer-key REST API with a free tier plus no-key public Research endpoints.

- **Provider:** https://coinnudge.site
- **Documentation:** https://coinnudge.site/data/api-docs
- **Base URL:** https://coinnudge.site/api/data/v1

## APIs

- **CoinNudge Research Data API** — REST/JSON+CSV API for crypto research datasets and market events. Bearer API key (cnd_ prefix) required for /api/data/v1 endpoints; free Research scope available. No-key public endpoints serve current Research datasets as JSON/CSV. No machine-readable spec (OpenAPI/AsyncAPI/GraphQL/Postman) published. (`https://coinnudge.site/api/data/v1`)
